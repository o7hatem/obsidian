# Phase 0: Problem Definition
> I'll leave it for now since I can make up any story I want later.

This is going to be a very simplified version of a automated recycling workflow.

V1 (this project): We will assume that the objects are linearly fed on a conveyer belt. Then a very simple robotic pushers, pushes the object into its designated pin.

V2: This will a very steep increase in difficulty from V1. So this is a very rough idea of what I want to do.

In this iteration we will robotic arms to pick up pieces of litter and put them in designated pins. This is going to be hard using object detection. Object segmentation will be a better choice in this use case. This will help the robotic arm to define dimensions for the object for easier pick up. 

This sounds like a industrial solution already. Would love to see where this is implemented in Egypt.
